===== Step 4: Step 2 – Build the sender / router / receiver network (namespaces)
[Terminal 1]

===== Step 5: Step 2 – Create the cables and assign interfaces
[Terminal 1]
$ sudo ip link add veth-s type veth peer name vr0; sudo ip link add vr1 type veth peer name veth-r; sudo ip link set veth-s netns sender; sudo ip link set vr0 netns router; sudo ip link set vr1 netns router; sudo ip link set veth-r netns receiver; sudo ip netns exec router ip link set vr0 name eth0; sudo ip netns exec router ip link set vr1 name eth1; sudo ip netns exec sender ip link set veth-s name eth0; sudo ip netns exec receiver ip link set veth-r name eth0; echo done
done

===== Step 6: Step 2 – Configure IP addresses
[Terminal 1]
$ sudo ip netns exec sender ip addr add 192.168.10.2/24 dev eth0; sudo ip netns exec router ip addr add 192.168.10.1/24 dev eth0; sudo ip netns exec router ip addr add 192.168.20.1/24 dev eth1; sudo ip netns exec receiver ip addr add 192.168.20.2/24 dev eth0; for n in sender router receiver; do sudo ip netns exec $n ip link set lo up; sudo ip netns exec $n ip link set eth0 up; done; sudo ip netns exec router ip link set eth1 up; echo done
done
